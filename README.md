# Сигма-7: программист-детектив

После метеоритного дождя диагностический пульт орбитальной станции выдаёт
неверные результаты. Связь с центром восстановлена, исходники доступны.
Ваша задача — найти и исправить **ровно шесть независимых логических ошибок**.
Ошибок синтаксиса в проект намеренно не внесено.

## Подготовка и запуск

Нужен **.NET SDK 8.0 или более новый SDK с поддержкой net8.0**. Одного Runtime
недостаточно. Внешние NuGet-пакеты не используются. При отсутствии локальных
компонентов net8.0 SDK может потребовать доступ к сети для восстановления.

Откройте терминал в этой папке (там, где находится README):

```text
dotnet build Sigma7/Sigma7.csproj -c Release
dotnet run --project Sigma7/Sigma7.csproj -- help
dotnet run --project Sigma7/Sigma7.csproj -- average 10 20 30
```

Без аргументов также выводится справка. Каждая команда запускает отдельную
диагностику; состояние между запусками не сохраняется. Пользовательские данные
передаются после `--`. Успешная команда завершает процесс с кодом 0,
неверный ввод — с кодом 2 и сообщением в стандартном потоке ошибок.

## Техническое задание — источник правильного поведения

| Команда | Правило |
| --- | --- |
| `average <показания...>` | Среднее арифметическое всех показаний. Дробная часть сохраняется. |
| `alarms <порог> <показания...>` | Тревога для каждого показания, которое **больше или равно** порогу. Вывести число таких показаний. |
| `minimum <показания...>` | Минимальное значение среди **всех** показаний. |
| `refuel <запас> <добавка>` | Создать бак с указанным запасом, затем добавить топливо к имеющемуся запасу. Вывести новый запас. |
| `crew <имя>` | Создать члена экипажа. Его свойство Name должно точно хранить переданное имя. |
| `access <пропуск> <PIN>` | Открыть шлюз только при одновременной успешной проверке пропуска **и** PIN. 1 — проверка успешна, 0 — нет. |

Допустимые данные:

- Показания: от 1 до 20 целых чисел, каждое от -100 до 100 включительно.
- Порог: целое число от -100 до 100 включительно, задаётся перед показаниями.
- Начальный запас и добавка: целые неотрицательные числа; их сумма не больше 100.
  Нулевая добавка разрешена и не должна менять запас.
- Имя: одна непустая и не состоящая только из пробелов строка. Имя с пробелами
  заключайте в кавычки: `crew "Анна Вега"`. Пробелы внутри имени сохраняются.
- Для access допустимы только два значения 0 или 1.

Обработка некорректных аргументов уже реализована в Program.cs. Публичные методы
предметной области вызываются только с данными из указанного диапазона;
проверка null, пустых массивов и недопустимых значений внутри этих методов
не входит в задание. Переполнение суммы в данном диапазоне невозможно.

Формат вывода: `average=<число>`, `alarms=<целое>`, `minimum=<целое>`,
`fuel=<целое>`, `crew=<имя>`, `access=OPEN` или `access=CLOSED`.
У среднего десятичный разделитель — точка, до 15 знаков после неё, лишние нули
не выводятся; при проверке вычислений допустима погрешность 0.000000001.

## Разведка

Попробуйте несколько корректных команд, затем придумайте свои граничные случаи:

```text
dotnet run --project Sigma7/Sigma7.csproj -- average 10 20 30
dotnet run --project Sigma7/Sigma7.csproj -- alarms 50 20 80
dotnet run --project Sigma7/Sigma7.csproj -- minimum 2 8 7
dotnet run --project Sigma7/Sigma7.csproj -- refuel 0 15
dotnet run --project Sigma7/Sigma7.csproj -- crew "Анна Вега"
dotnet run --project Sigma7/Sigma7.csproj -- access 1 1
```

Не все неисправности проявляются на обычных данных. Сопоставляйте результат
с техническим заданием, а не с текущим кодом.

## Исходники и границы работы

- `Sigma7/Program.cs` — разбор команд, проверка данных и вывод.
- `Sigma7/Telemetry.cs` — обработка показаний датчиков.
- `Sigma7/FuelTank.cs` — состояние топливного бака.
- `Sigma7/CrewMember.cs` — регистрация экипажа.
- `Sigma7/Airlock.cs` — разрешение на открытие шлюза.

Сохраняйте имена классов, публичных методов и свойств, сигнатуры, формат команд
и вывода. Исправляйте причины ошибок, не подставляйте ответы для конкретных
примеров. Не нужно добавлять интерфейсы, наследование, LINQ, коллекции,
асинхронность, файловое хранилище или сторонние библиотеки.

Используются темы первых трёх глав [учебника Metanit](https://metanit.com/sharp/tutorial/):
запуск консольного проекта; типы, арифметика, условия, циклы, массивы и методы;
классы, конструкторы, пространства имён, свойства и статические члены.
Это выбор тем из этих глав, а не упражнение на каждый их подраздел.
Оглавление сверено 17.11.2026. Базовые вызовы библиотеки для разбора чисел,
кодировки и вывода уже даны в оболочке и не требуют изучения новых механизмов языка.
